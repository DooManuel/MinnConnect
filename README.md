# MinnConnect

**A cross-platform mobile app for parents and teachers at Minn Cedar Private School (Lagos, Nigeria).**

MinnConnect is designed to help parents stay connected with their children’s education and school activities. The app provides a **comprehensive platform** to track academic progress, receive notifications, communicate with teachers, and stay updated with school events.

---

## 📱 Features

### Dashboard
- Overview of all children (with “My Kids” dropdown for parents with multiple kids)
- Quick access to academic progress, notifications, and events

### Finances
- View fee categories (tuition, uniforms, etc.)
- Payment instructions and manual payment confirmation

### Academics
- Homework journal with file attachments and automated tracking
- Progress reports and report cards in PDF
- Rewards and badges for completing weekly tasks
- Feedback from teachers

### Daily Feed
- Social-media style timeline of class activities
- Photos, captions, and emoji reactions
- Whole-school and class-specific updates

### My Teacher
- Direct chat with multiple teachers
- Read receipts and typing indicators

### Announcements & Alerts
- Class-level and school-wide notifications
- Push notifications for urgent alerts

### Extra Enhancements
- Morning motivation messages from the headmistress
- Digital handbook / school rules section
- Event RSVPs (e.g., PTA attendance confirmation)

---

## 🛠 Technologies
- **Frontend:** React Native (cross-platform iOS & Android)
- **Backend:** Firebase (Authentication, Firestore Database, Cloud Storage)
- **Version Control:** Git & GitHub
